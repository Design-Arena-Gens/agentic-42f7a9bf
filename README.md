# 15‑Minute EMOM Dumbbell Workout

A zero‑setup static web app that runs a simple, boring, effective 15‑minute EMOM full‑body workout using only a pair of 5 kg dumbbells.

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
```
vercel deploy --prod --yes --token $VERCEL_TOKEN --name agentic-42f7a9bf
```

Then verify:
```
curl https://agentic-42f7a9bf.vercel.app
```
